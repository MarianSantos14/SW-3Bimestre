                                                                    Ruan Carvalho Mod Albuquerque • 4 anos atrás

                                                                    Albuquerque, você precisa tentar encontrar onde está o erro. Pode ser até um problema no seu servidor local, ou no banco de dados também.

                                                                    Só dizer que não funciona não ajuda muita coisa. Você tem que conseguir alguma mensagem de erro.

                                                                    Primeiro, verifica a aba console do debug do navegador (F12, no chrome) e vê se dá alguma mensagem.

                                                                    Depois, crie logs de erro em cada função no código (um print, ou uma mensagem). Assim, você pode achar qual função está quebrando.

                                                                    Por exemplo, coloque um print_r em cada função dos arquivos. Aí você vai saber onde parou e o porquê.
